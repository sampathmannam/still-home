# Still Home interface

An Android phone owner wants a dark, understandable privacy setup while retaining
existing AI and everyday functionality. The existing identity is deep slate with
muted teal. Preserve it across releases.

Use Android Views, system sans-serif text in sp, dark/light role colors, native
Android confirmation screens, buttons with 48dp or larger targets, system Back,
keyboard/system-bar insets, and a navigation rail on wider screens. Use subdued
surfaces and reserve teal for actions, selection, and directly checked conditions.

The setup has six steps, one primary forward action, a visible way to stop and
resume, and small explanations beside decisions. No security score, fake checks,
anonymity promises, hidden blanket permissions, or unexplained package names.
Distinguish live readings, installed apps, and user review notes. Saving a tour does
not mean all privacy controls are enabled. Retain access to AI and rollback controls.
